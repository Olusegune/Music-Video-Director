# MotionForge Studio

## UI / UX Design Specification

Version 1.0

---

# Design Vision

MotionForge is not a chatbot.

MotionForge is a cinematic production workspace.

Users should feel like they are building a film, commercial, motion graphic, or creative campaign.

The experience should resemble:

* Figma
* Linear
* Notion
* Frame.io
* DaVinci Resolve
* Arc Browser

Avoid:

* ChatGPT-style conversation-first interfaces
* Prompt-box-only workflows
* Endless scrolling outputs

---

# Core UX Philosophy

The AI is a collaborator.

Not the product.

The project is the product.

Every user action should be attached to a project.

Everything generated becomes editable assets.

---

# Design Principles

## Principle 1

Visual First

Users should see:

* Storyboards
* Shots
* Timelines
* Moodboards

before long text.

---

## Principle 2

Project Based

Everything lives inside:

Project
→ Scene
→ Shot
→ Prompt

Hierarchy.

---

## Principle 3

Editable Everywhere

Every AI output is editable.

No locked outputs.

---

## Principle 4

Professional Tooling

Feels like creative software.

Not a chatbot.
