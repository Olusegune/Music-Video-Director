# Installing Director Studio 1.0.0

Use one of the Windows installers from:

```text
C:\Users\eduni\Documents\DirectorStudio-Release-1.0.0\Installers\
```

Or run the portable build from:

```text
C:\Users\eduni\Documents\DirectorStudio-Release-1.0.0\Portable\DirectorStudio-1.0.0-Portable\
```

## SmartScreen

If this build is unsigned, Windows may display an "unrecognized app" prompt.

1. Click **More info**.
2. Confirm the app name is **Director Studio**.
3. Click **Run anyway** if you trust the build source.

## Portable mode

The portable folder includes:

- `Director Studio.exe`
- `portable.txt`
- `data\`
- `README.txt`

Keep those files together. The app stores portable data inside the local `data\` folder.
